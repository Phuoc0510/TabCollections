🏗️ Data Model Changes

storage.js — thêm fields

// Group object — thêm:
{
  ...existing,
  pinned: false,           // boolean, pin lên đầu
  deletedAt: null,         // timestamp nếu bị soft-delete
}

// Tab object — thêm:
{
  ...existing,
  deletedAt: null,         // timestamp nếu bị soft-delete
}

Thay đổi storage functions

  • getGroups() — filter bỏ groups có deletedAt, sort pinned lên trước
  • getTabsByGroup() — filter bỏ tabs có deletedAt
  • deleteGroup(id) → softDeleteGroup(id) — set deletedAt: Date.now() thay vì xóa hẳn
  • removeTab(id) → softRemoveTab(id) — set deletedAt: Date.now()
  • restoreGroup(id) + restoreTab(id) — mới, xóa deletedAt
  • purgeDeleted() — mới, hard-delete items có deletedAt < 30s ago

background.js — cleanup timer

  • Thêm chrome.alarms hoặc setInterval trong SW
  • Mỗi 15s: gọi purgeDeleted() để cleanup items quá 30s
