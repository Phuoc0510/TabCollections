📋 Tổng hợp & Approach

Ưu đã confirm:

  • 🔍 Search: Thanh search trong header, filter realtime theo tên collection + tab title + URL
  • 📌 Pin: Icon 📌 trên card, click để pin/unpin, ghim lên đầu
  • 🔄 Grid/List: Toggle trong header, list view expandable
  • 🗑️ Undo: Toast bar kiểu Gmail, 30s, xóa collection = xóa cả tabs (undo được)

So sánh 2 approach cho Undo

Approach A: In-memory undo (đơn giản hơn)

  • ✅ Chỉ cần setTimeout + biến tạm trong JS
  • ❌ F5 / đóng tab là mất cơ hội undo
  • ❌ Toast dễ bị mất sync nếu nhiều storage change

Approach B: Soft-delete trong storage (đề xuất ✅)

  • ✅ Data ở trong chrome.storage — reload trang vẫn undo được
  • ✅ Dùng deletedAt field + cleanup timer ở background.js
  • ❌ Phải code cleanup workers (setTimeout trong SW)

Tôi đề xuất Approach B (Soft-delete) cho undo vì extension data quý hơn in-memory tạm. Các features còn lại implement trực tiếp vào file hiện tại, giữ style code đơn giản.
