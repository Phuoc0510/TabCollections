🗑️ Undo / Trash Design

Soft-Delete Flow

Khi user click Delete:
1. softDeleteGroup(id) → set group.deletedAt = Date.now()
2. softDeleteTab(id) → set tab.deletedAt = Date.now()
3. Toast bar hiện: "Deleted "Work" — ↩️ Undo"
4. Items biến mất khỏi grid (getGroups/getTabsByTab filter ra)

Nếu user click Undo (trong 30s):
5. restoreGroup(id) → set deletedAt = null
6. restoreTab(id) → set deletedAt = null
7. Items xuất hiện lại, render → hide toast

Nếu hết 30s:
8. purgeDeleted() → xóa hẳn items có deletedAt < now - 30000
9. Toast tự ẩn

Toast UI

Vị trí: Fixed bottom-center, z-index cao nhất
Style: Nền tối, chữ trắng, bo góc
Nội dung: "Deleted 'X'" + nút "Undo" màu primary
Countdown: Thanh progress bar 30s chạy ngang
Tự động: Ẩn sau 30s hoặc khi click Undo

Storage & Background

  • background.js — message handlers, setInterval(purgeDeleted, 15000)
